# КВАДРАТ — обновлённый прототип

## Запуск локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для надёжной работы всех страниц предпочтительно запускать через локальный HTTP-сервер, например `python -m http.server 8000`, затем открыть `http://localhost:8000`.
3. Каталог, фильтры, дизайн-страницы и демо-конфигуратор используют JavaScript без сборщика.

## Что улучшено

## Что пока не является production
- Каталог не синхронизируется с системами застройщиков в реальном времени.
- Планировки квартир пока не импортированы в базу «КВАДРАТ»; пользователь переходит к официальному источнику, чтобы проверить наличие и варианты.
- Если подтверждённой планировки нет, конфигуратор позволяет сделать отдельный расчёт только по вручную введённой площади; это не объявляется реальной квартирой.
- Расчёт ремонта и цены материалов в конфигураторе — демонстрационная модель, не коммерческая оферта.
- Заявки и избранное сохраняются в `localStorage` текущего браузера; заявки не отправляются менеджеру.
- Админ-панель исходного проекта не защищена авторизацией на сервере; её нельзя использовать для управления коммерческими данными.
- Фотографии и рендеры взяты с сайтов застройщиков как ссылки на источник. Перед публичным коммерческим использованием необходимо подтвердить права на повторную публикацию и при необходимости получить письменное разрешение.
