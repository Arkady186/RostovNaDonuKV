# КВАДРАТ — обновлённый прототип

## Запуск локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для надёжной работы всех страниц предпочтительно запускать через локальный HTTP-сервер, например `python -m http.server 8000`, затем открыть `http://localhost:8000`.
3. Каталог, фильтры, дизайн-страницы и демо-конфигуратор используют JavaScript без сборщика.

## Что пока не является production
- Каталог не синхронизируется с системами застройщиков в реальном времени.
- Планировки квартир пока не импортированы в базу «КВАДРАТ»; пользователь переходит к официальному источнику, чтобы проверить наличие и варианты.
- Если подтверждённой планировки нет, конфигуратор позволяет сделать отдельный расчёт только по вручную введённой площади; это не объявляется реальной квартирой.
- Расчёт ремонта и цены материалов в конфигураторе — демонстрационная модель, не коммерческая оферта.
- Заявки и избранное сохраняются в `localStorage` текущего браузера; заявки не отправляются менеджеру.
- Админ-панель исходного проекта не защищена авторизацией на сервере; её нельзя использовать для управления коммерческими данными.
- Фотографии и рендеры взяты с сайтов застройщиков как ссылки на источник. Перед публичным коммерческим использованием необходимо подтвердить права на повторную публикацию и при необходимости получить письменное разрешение.

## Аккаунты, избранное, отзывы и админ-панель (новое)

Теперь сайт работает вместе с небольшим сервером `server.js` (Node.js 18+, без зависимостей). Просто открыть html-файлы двойным кликом уже не получится — вход и CRM требуют сервера.

**Запуск:** двойной клик по `start.bat` или `node server.js`, затем http://localhost:3000.
При первом запуске создаётся администратор: телефон `+79000000000` (или значение переменной `ADMIN_PHONE`) и случайный пароль, который выводится в консоль один раз. Свой пароль можно задать переменной `ADMIN_PASSWORD` или командой `node server.js reset-admin +79001234567 НовыйПароль1`.

- `login.html` — вход и регистрация (телефон, имя, пароль + повтор, согласие на обработку ПД и пользовательское соглашение).
- `privacy.html`, `terms.html` — политика обработки персональных данных и пользовательское соглашение. **Жёлтым выделены поля с реквизитами компании — заполните их и покажите юристу.**
- `favorites.html` — без входа показывает «Авторизуйтесь».
- `reviews.html` — отзывы со звёздами. Три примера с 5★ помечены «Пример отзыва» и не входят в рейтинг; настоящие отзывы идут на модерацию, после отправки клиент видит благодарность.
- `admin.html` — CRM для менеджеров: клиенты, телефон, имя, где остановился (шаг конфигуратора / смета / заявка), воронка «где отваливаются», статусы звонков, заметки, карточка клиента с историей действий. Администратор дополнительно: создание аккаунтов менеджеров с паролем, модерация отзывов, журнал действий, CSV, удаление клиентов. `admin-catalog.html` — прежний демо-редактор каталога (только администратор).

**Безопасность:** данные клиентов лежат только на сервере (`data/db.json`), в браузер не попадают; пароли — scrypt-хеш; вход — HttpOnly-cookie (через F12 её не прочитать); все запросы к CRM проверяются сервером по роли; защита от CSRF и перебора паролей; `data/`, `server.js` и служебные файлы по HTTP не отдаются.
