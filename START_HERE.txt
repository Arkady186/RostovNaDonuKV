КВАДРАТ — как запустить

1. Распакуйте весь архив, не открывайте index.html прямо из ZIP.
2. Для простого просмотра откройте index.html в браузере.
3. Для корректной работы всех страниц рекомендуемый вариант:
   - установите Python 3, если он не установлен;
   - откройте терминал в папке проекта;
   - выполните: python -m http.server 8000
   - откройте http://localhost:8000
4. Каталог ЖК содержит официальные ссылки и изображения/рендеры с сайтов застройщиков.
5. Реальные планировки не подменяются схемами из исходного шаблона. Если они не импортированы, сайт предлагает проверить их на официальном сайте и позволяет сделать отдельный предварительный расчёт только по введённой площади.
6. Перед публичным коммерческим запуском обязательно выполните LAUNCH_CHECKLIST.md и согласуйте права на изображения.

Важно: это обновлённый фронтенд-прототип. Заявки пока не уходят на сервер; цены и ставки ремонта в конфигураторе демонстрационные.

ВАЖНО: сайт теперь запускается через сервер.
Windows: двойной клик по start.bat, затем откройте http://localhost:3000
Пароль первого администратора показывается в окне один раз.
Админ-панель: http://localhost:3000/admin.html
